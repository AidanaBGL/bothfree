# BothFree — 13 отдельных HTML-страниц (без чата)

Откройте `index.html` в браузере. Все экраны доступны через меню слева. Каждый экран — отдельный `.html` файл; прямые ссылки на файлы тоже работают.

## Структура

- `index.html` — Главная
- `01-scenario.html` — Выбор сценария
- `02-login.html` — Вход / режим жюри
- `03-profile.html` — Профиль
- `04-interests.html` — Интересы
- `05-calendar.html` — Свободное время
- `06-invite.html` — Пригласить знакомого
- `07-friends.html` — Найти друзей
- `08-dating.html` — Найти пару
- `09-matches.html` — Совпадения
- `10-meeting.html` — План встречи
- `11-map.html` — Выбор места (схематичная карта)
- `12-confirmation.html` — Подтверждение
- `styles.css` — Общие стили
- `app.js` — Общая логика и контент страниц

Это демонстрационная версия: реальные авторизация, email, алгоритм подбора, карты и оплата не подключены. Данные сохраняются только в рамках вкладки браузера через sessionStorage (если доступно). Чат отсутствует.

Для разработки с локальным сервером (необязательно):

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000/ .
